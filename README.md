# Olfa-Lietuva

Statinė OLFA Lietuva svetainė – originalūs OLFA peiliai, ašmenys ir pjaustymo kilimėliai.

## Struktūra

```
index.html        Pagrindinis puslapis
produktai.html    Produktų apžvalga pagal tipą (modeliai iš DziugasM9000/OLFA katalogo)
assets/
  css/styles.css  Stiliai
  js/main.js      Skriptai
  img/            Nuotraukos ir logotipas
```

## Paleidimas

Svetainė neturi build žingsnio – tiesiog atidarykite `index.html` naršyklėje
arba paleiskite vietinį serverį:

```
npx serve .
```

## Pastaba

Pirkimo nuorodos veda į parduotuvę `https://olfa-olfa.com`.
