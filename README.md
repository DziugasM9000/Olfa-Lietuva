# Olfa-Lietuva

Statinė OLFA Lietuva svetainė – originalūs OLFA peiliai, geležtės ir pjaustymo kilimėliai.

## Struktūra

```
index.html        Pagrindinis puslapis
xh-1.html         OLFA XH-1 produkto puslapis
assets/
  css/styles.css  Stiliai
  js/main.js      Skriptai
  img/            Nuotraukos ir logotipas
```

## Paleidimas

Svetainė neturi build žingsnio – tiesiog atidarykite `index.html` naršyklėje
arba paleiskite vietinį serverį:

```
npx serve .
```

## Pastaba

Pirkimo nuorodos šiuo metu veda į laikiną adresą `https://jusu-parduotuve.myshopify.com`.
Kai turėsite tikrą Shopify adresą, pakeiskite jį visuose `.html` failuose.
